### 2026-10-22 · 定时问题修复 + Step 2（驱动因素）完成
- **问题**：GitHub 定时任务在这里会延迟 3–5 小时，早上拿不到新简报。
- 试过 cron-job.org，测试运行出错，放弃（已提醒删除该任务和 token）。

- **Step 2 结论**（1980–2026，共 16,890 天）：
  - 气压：−0.91 cm/hPa，解释约 17% 的变化。但潟湖和外海一起抬升，所以**不影响水道流**。
  - 约 79% 是大洋整体变化，也不影响水道流。
  - 真正相关的是**西向涌浪泵水**：西浪 <2 m 约 0；2–2.5 m +0.7 cm；2.5–3 m +1.7 cm；≥3 m +2.8 cm。当天或次日达到峰值，约第 4 天消退。
  - 东浪、风、雨的影响可以忽略。
  - 推论：Malakal 实时残差不适合当"潟湖满了"的指标，改用浪高预报来估算涌浪泵水。

### 2026-11-10 · 项目 1、项目 2 完成，简报潮汐换成自己算
- **项目 1：潟湖和外海的潮汐差**（3 个全球潮汐模型 EOT20、GOT4.10c、GOT5.6，取西侧外海两个点）：
  - Malakal 比西侧外海晚：M2 约 20 分钟，K1 约 35 分钟；振幅大 2–5%。
  - 潟湖和外海的最大水位差：小潮 5–6 cm，中潮 7–12 cm，大潮 16–18 cm。
  - 西侧强涌（+2.8 cm）约等于小潮推力的一半，大潮推力的六分之一。它会让 incoming 晚开始、早结束：小潮时前后各约 65 分钟，大潮时各约 25 分钟。
  - 水位差在 Malakal 高潮前约 35–40 分钟反转，所以水道转流大约在 Malakal 高低潮前后。
  - "小潮 + 西浪 ≥ 2.5 m"一年不到 1 天；"≥ 2.0 m"一年约 3–4 天。
  - **改动**：乌龙、德国的延迟从 45 改为 **0 分钟**；当天最大潮差 < 1.0 m 时，涌浪再多扣 1 分。
- **项目 2：自有潮汐常数**（回测 2011–2026，187 个窗口，约 25,000 个高低潮）：
  - 自己算的：高低潮时间平均误差 **9 分钟**，没有系统偏差。
  - NOAA：平均误差 17.5 分钟，**系统性晚约 18 分钟**，每年都一样。
  - 常数放一年不更新、或者缺 90 天数据，误差也几乎不变。
  - **改动**：简报潮汐改为自己的常数（最近 365 天实测拟合），NOAA 时间以小字"tables HH:MM"保留，并作备用。
  - 每月 3 日自动重拟合，有质量检查。上线当天就发现 IOC 实时数据的传感器在 11-02 前后跳了约 3 米，已加过滤。
  - 我们的高低潮时间比 NOAA 和 Tide Forecast 早约 15–18 分钟，这是对的。

## 3. 当前技术架构

```
GitHub Actions（push / 手动 / 定时，每晚多次）
   ├─ 潮汐：自有调和常数 data/tide_constants.json（每月 3 日自动重拟合，带质量检查）
   │        NOAA CO-OPS Malakal 1841367 只作"tables"时间和备用
   ├─ 天气：Open-Meteo 海况 + 天气（west-south / west-north / east；Koror 点给天空、雨、日出日落）
   │        NWS 关岛 CWF（PMZ161），只显示比小船警报更强的
   ├─ 生成 docs/data/brief.json（不提交，镜像到 brief-data 分支，失败时用上一份兜底）
   └─ 部署 docs/ → GitHub Pages
分析：analysis-*.yml 工作流，结果放在 analysis-data 分支（step1/、tides/、noaa/、project3/、project10/）
文档：analysis/<项目>/（各项目详细记录）、notes/（项目总文档的镜像）
iPhone 主屏幕 App：Service Worker 离线缓存，回到前台自动刷新
覆盖范围：过去 15 天 + 未来 34 天潮汐，8 天天气
```

**流速模型**：潜点在时刻 t 的流 = Malakal 在 (t − lag) 时的潮位变化
- 低潮→高潮 = 进流，高潮→低潮 = 出流；变化率低于峰值 30% 算平潮。
- 流强 1–5 级：变化率分界 10/20/30/40 cm/h，乘以强度系数。
- 潮差表 1–5 级：按潮差比分（<0.7、<0.85、<1.15、<1.3、更大）。

**可信度评分**：起始 10 分。
- 潮差比：<0.7 −3、<0.85 −2、<1.15 −1。
- 西涌泵水：−1 / −2 / −3。
- 小潮（潮差比 < 0.85）时涌浪再 −1；当天最大潮差 < 1.0 m 时再 −1。

**界面要点（Lowis 定的）**：
- 标题"MM-DD HH:MM Brief"；风和浪的方向表盘（风显示"21/27 kn"）；月相图标；潮差表；涌浪泵水行。
- 可信度分数加因素标签一行。
- 潮汐图：有计划时间线、逐时刻度；高低潮 4 格，带"tables"小字。
- 潜点卡片、海况表、"Next days"面板、彩色"current found"按钮。
- 页脚有免责声明和 © 2026 Lowis Wong。
